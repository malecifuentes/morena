# Multi-Bakery Subscription Platform

## Overview

This project is a subscription-based digital platform designed for small bakeries and dessert businesses.

The platform allows multiple bakeries, operating as independent tenants, to manage their own products, prices, branding and online order requests. Morena is the pilot bakery used to validate the platform before onboarding additional bakery tenants.

## Live Prototype

The current Morena Bakery prototype is available at:

https://malecifuentes.github.io/morena/

### Currently Working

- Product Catalogue
- Product Details and Pricing
- Quantity selection
- Navigation from the catalogue to product details
- Navigation from product details back to the catalogue

### Not Yet Connected

- Online order request form
- Order request confirmation

## Problem

Many small bakeries currently receive customer orders manually through WhatsApp, Instagram or other social media channels. Customers often need to exchange several messages to ask about available products, prices, quantities and delivery dates. This process can create delayed responses, incomplete information and difficulties organising customer requests.

## Solution

The platform provides each bakery with its own digital storefront where customers can:

- Browse the bakery’s product catalogue.
- View product details, prices and availability.
- Submit an online order request.
- Receive confirmation that the request was recorded.

Each bakery’s products, branding and customer requests remain separated through tenant-based data rules.

## Core MVP Features

- Product catalogue
- Product details and pricing
- Online order request
- Order request confirmation
- Tenant-based separation of bakery data

## Pilot Bakery

Morena is the first bakery configured in the platform. It will be used to validate the ordering experience before the platform is expanded to additional bakery tenants.
