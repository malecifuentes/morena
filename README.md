# Morena

Morena helps people in Guatemala City order homemade desserts quickly and easily without having to exchange multiple messages to check products, prices, and availability. Customers can **view available products**, **see prices**, and **submit a basic order request** in one place.

## The three Musts

- View the available products
- View product prices
- Submit an online order request

## Core features at a glance
| Feature | Priority |
|---|---|
| Product catalogue | Must |
| Product prices | Must |
| Online order request | Must |
